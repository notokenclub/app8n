## What is App8n?

**App8n is an open-source workflow automation platform that brings powerful automation into a simple, app-like experience.**

Think visual workflows, integrations, triggers, actions, and powerful automation — built in a way that is accessible to everyone.

We are building a platform where you can:

* 🔗 Connect your favorite apps and services
* ⚡ Create automated workflows visually
* 🧩 Build using reusable nodes and integrations
* 🤖 Add AI-powered steps to workflows
* 🔌 Extend the platform with custom integrations
* 🌍 Contribute to an open-source ecosystem

**App8n isn't just another app. It's a project we want the community to build with us.**

---

## Why are we building this?

Automation tools are powerful.

But we believe building and experimenting with automation should be more **open, accessible, and community-driven**.

So instead of simply creating a project behind closed doors, we're building App8n in public.

We want developers, designers, AI enthusiasts, students, builders, and curious people to be able to:

* Explore how workflow automation platforms are built
* Contribute real features
* Build integrations
* Improve the product
* Learn from the codebase
* Collaborate with other builders

The goal isn't just to create software.

**The goal is to create something people can learn from, contribute to, and be proud to build together.**

## What We're Building

App8n will focus on creating a workflow automation experience around:

### 🔗 Integrations

Connect applications, APIs, databases, and services.

### ⚡ Workflow Builder

Create workflows using a visual node-based interface.

### 🧩 Nodes

Every workflow is made up of reusable building blocks.

Triggers.
Actions.
Logic.
Data transformations.
AI.
And more.

### 🤖 AI Workflows

Build automation that can work with modern AI models and tools.

### 🔌 Extensibility

Developers should be able to build custom nodes, integrations, and functionality.

### 🏃 Workflow Execution

Workflows should be able to run reliably, process data, and execute across connected services.
